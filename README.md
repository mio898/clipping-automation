# Clipping-Automatik

Schneidet GTA-6-Momente automatisch zu Hochformat-Clips (Remotion, WhisperX, Real-ESRGAN, Claude Code).
Läuft alle 15 Minuten über GitHub Actions: liest neue Momente aus einem Google-Drive-Ordner und legt fertige Clips dort ab.
Postet nichts. Zugangsdaten liegen ausschließlich in GitHub Secrets.
